🏥 RuralCare: Platform Strategy for Field-Data Collection

Requirements: 10-hour shift on single battery charge; offline for hours; zero data loss; protected patient data at rest and in transit.
• Class A: Modern Android smartphones.
• Class B: iPhones.
• Class C: Legacy feature phones supporting only J2ME/JME or WML browser.
Device Class Runtime & Framework Security at Rest Offline Storage Engine Power Policy (10-hr Shift)
Class A (Android) ART Runtime, Kotlin Native + WorkManager SQLCipher AES-256 with AndroidKeyStore Local Room / SQLite DB Batch sync on Wi-Fi/LTE connect; sensor batching
Class B (iOS) Native Swift + CoreData / BGAppRefresh Data Protection API (Class Complete FileVault) Encrypted SQLite / CoreData Background Processing tasks during charging
Class C (J2ME) KVM / CLDC 1.1 + MIDP 2.0 RecordStore encrypted with user PBKDF2 PIN Record Management System (RMS) Zero background daemon; manual sync on button press

🧪 Desk-Check: Lost Phone Scenario & Adversarial Stress Tests

Stage 5 Desk-Check:
A Class A health worker is offline for 6 hours, collects 42 patient records. Battery falls to 20%. Device is lost before sync.
1. Device locks after 60s screen timeout.
2. Patient Records: Encrypted under AES-256-GCM. Decryption key is bound to secure hardware chip and user biometric PIN.
3. Data Exposed: ZERO plaintext patient data exposed.
4. Data Recoverability: Records remain stored safely in flash memory. When recovered or remotely wiped via MDM server, confidentiality is preserved.
Stage 6: Adversarial Attack Tests:
• Attack 1: Stolen Unlocked Phone: App enforces secondary in-app biometric/PIN re-authentication after 5 minutes of inactivity.
• Attack 2: Corrupted Sync Mid-Transfer: All records use UUID idempotency keys and chunked transactions. If connection drops at packet 4 of 10, backend commits only verified chunks; client resumes from chunk 5 upon reconnect.
• Attack 3: Class C Feature Phone with No Hardware Keystore: App uses software AES-128 with key derived from operator PIN via PBKDF2 (10,000 rounds).
