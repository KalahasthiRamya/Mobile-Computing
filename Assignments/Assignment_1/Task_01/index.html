📋 Guiding Enquiry & Strategy Formulations

How can a fixed block of spectrum (336 duplex voice channels) be shared across a 12 km² university township without intolerable co-channel interference?

Strategy 1: Fixed Cluster Reuse (FCA)
• Design Principle: Spatial Reuse via regular tessellation ($N = i^2 + ij + j^2$).
• Channels per cell: $C = \lfloor 336 / N floor$.
• Access Channels: FDMA/TDMA. Control channels (BCCH/CCCH) reserved separately from traffic channels (TCH).
• Preprocessing: Propagation survey, terrain clutter map, hex grid layout. Cost borne by network operator.

Iterative Cluster & Channel Assignment

ALGORITHM AssignFixedClusterChannels(TotalChannels, i, j)
INPUT:
  TotalChannels – 336 duplex channels
  i, j – non-negative shift coordinates
OUTPUT:
  ClusterSize N, ChannelGroups
BEGIN
  N ← (i * i) + (i * j) + (j * j)
  IF N = 0 THEN
    RETURN ERROR_INVALID_CLUSTER
  END IF
  ChannelsPerCell ← FLOOR(TotalChannels / N)
  FOR k ← 0 TO N - 1 DO
    ChannelGroups[k] ← EMPTY_SET
    FOR ch ← 1 TO TotalChannels DO
      IF (ch MOD N) = k THEN
        ADD ch TO ChannelGroups[k]
      END IF
    END FOR
  END FOR
  RETURN N, ChannelGroups
END

Recursive Hierarchical Cell Splitting

ALGORITHM RecursiveCellSplit(Cell, TargetDemand, Radius, Power, MaxDepth)
INPUT:
  Cell, TargetDemand, Radius R, TransmitPower P, MaxDepth
OUTPUT:
  SubdividedNetworkTree
BEGIN
  OfferedTraffic ← ComputeTraffic(Cell)
  IF OfferedTraffic ≤ Cell.Capacity OR MaxDepth = 0 THEN
    RETURN Cell  // Demand satisfied without split
  END IF
  NewRadius ← Radius / 2
  NewPower ← Power / (2 ^ PathLossExponent)
  ChildCells ← GENERATE_4_SUB_HEXAGONS(Cell.Center, NewRadius)
  FOR each Child in ChildCells DO
    Child.Power ← NewPower
    RecursiveCellSplit(Child, TargetDemand / 4, NewRadius, NewPower, MaxDepth - 1)
  END FOR
  RETURN ChildCells
END
