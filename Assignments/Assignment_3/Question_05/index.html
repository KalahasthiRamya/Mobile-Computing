📋 Proactive Routing: DSDV Operation & Sequence Numbers

Destination-Sequenced Distance-Vector (DSDV):
• Every node maintains a routing table listing every possible destination.
• Sequence Numbers: Originated by destination. Prevents routing loops and count-to-infinity problems.
• Route Update Rule: A route update is accepted if:
$$ ext{NewSeq} > ext{OldSeq} \quad ext{OR} \quad ( ext{NewSeq} = ext{OldSeq} ext{ AND } ext{NewMetric} < ext{OldMetric})$$
