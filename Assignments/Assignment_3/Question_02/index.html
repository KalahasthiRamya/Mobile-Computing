🚨 Joint Design Question: Frequent Handover Mitigation

Problem Statement: If a mobile user frequently changes network of attachment during an active session, registration signaling messages must travel across the wide-area Internet to the Home Agent repeatedly, causing high latency, packet drops, and signaling storms.

Proposed Solution (Hierarchical Mobile IP / HMIPv6):
Introduce a Mobility Anchor Point (MAP) in the visited domain. When moving between local access points within the foreign domain, the MN registers only with the local MAP (Micro-mobility). The Home Agent is only updated when moving across major domains (Macro-mobility). This slashes registration delay from $pprox 250 ext{ ms}$ to $< 15 ext{ ms}$.
