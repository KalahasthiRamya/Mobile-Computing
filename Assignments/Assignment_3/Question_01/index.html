📜 Student B Mobility Decision Algorithm (SIMATS Pseudocode)

ALGORITHM EvaluateHandoffDecision(MN, CurrentAP, CandidateAPList, HysteresisDelta, MinThreshold)
INPUT:
  MN – mobile node
  CurrentAP – currently associated access point
  CandidateAPList – set of detected AP beacons
  HysteresisDelta – margin to prevent ping-pong (e.g. 5 dB)
  MinThreshold – minimum acceptable signal (-75 dBm)
OUTPUT:
  HandoffDecision (TRIGGER_HANDOFF or MAINTAIN_CONNECTION)
BEGIN
  CurrentRSSI ← MeasureRSSI(CurrentAP)
  IF CurrentRSSI ≥ MinThreshold THEN
    RETURN MAINTAIN_CONNECTION
  END IF
  BestCandidate ← NULL
  MaxRSSI ← -INFINITY
  FOR each AP in CandidateAPList DO
    BeaconRSSI ← MeasureRSSI(AP)
    IF BeaconRSSI > MaxRSSI THEN
      MaxRSSI ← BeaconRSSI
      BestCandidate ← AP
    END IF
  END FOR
  IF MaxRSSI > (CurrentRSSI + HysteresisDelta) THEN
    PERFORM_SCAN_AND_ASSOCIATE(MN, BestCandidate)
    RETURN TRIGGER_HANDOFF
  END IF
  RETURN MAINTAIN_CONNECTION
END
