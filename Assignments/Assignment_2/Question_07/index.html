⚡ DAY-4 DESIGN CHALLENGE (13 MARKS)

🔬 A. Diagnose the Bottleneck (2 Marks)

Diagnosed Bottleneck: Dedicated FDMA/TDMA channels sit idle 88-90% of the time under bursty telemetry / IoT traffic.
• In dedicated channel assignment, a 25 kHz carrier or 200 kHz time slot is allocated permanently for the duration of a session.
• Sensor devices transmit short 200-byte packets intermittently (10% duty cycle). During the remaining 90% idle holding time, no other device can access the spectrum, resulting in severe capacity collapse and premature blocking.

🎯 B. Define Design Objective (2 Marks)

Measurable Objectives:
1. Increase channel utilization from $\mathbf{12\%}$ to $\mathbf{\ge 75\%}$.
2. Support at least $\mathbf{6\times}$ more concurrent telemetry devices within the same 2 MHz spectrum.
3. Maintain packet loss probability below $\mathbf{1\%}$.

🛠️ C. Revised Strategy: PRMA / Slotted Aloha Hybrid (4 Marks)

ALGORITHM DynamicPacketReservation(Device, Slot, Packet)
INPUT:
  Device, Slot – current TDMA frame slot, Packet
OUTPUT:
  SlotStatus
BEGIN
  IF Slot.Status = RESERVED AND Slot.Owner = Device.ID THEN
    TRANSMIT Packet IN Slot
    IF Packet.IsEndOfMessage THEN
      RELEASE Slot.Reservation
    END IF
    RETURN TRANSMIT_SUCCESS
  ELSE IF Slot.Status = IDLE THEN
    // Contention phase via Slotted-Aloha with permission probability p
    IF RANDOM(0.0, 1.0) ≤ Device.PermissionProbability THEN
      TRANSMIT ReservationRequest IN Slot
      IF BaseStation.DetectsCollision(Slot) = FALSE THEN
        Slot.Status ← RESERVED
        Slot.Owner ← Device.ID
        RETURN RESERVATION_GRANTED
      ELSE
        EXECUTE ExponentialBackoff(Device)
        RETURN COLLISION_BACKOFF
      END IF
    END IF
  END IF
  RETURN SLOT_SKIPPED
END

🛡️ F. Defend the Final Design (2 Marks)

Trade-Offs & Defense:
• Hypothesis Confirmed: Transitioning from circuit-switched static reservation to dynamic contention-based packet reservation multiplies device density by $6.5 imes$ without allocating additional RF bandwidth.
• New Trade-off: Under extreme packet bursts ($p o 1.0$), contention collisions increase packet latency from $15 ext{ ms}$ to $pprox 65 ext{ ms}$. For telemetry and IoT monitoring, a $65 ext{ ms}$ delay is completely benign, making PRMA far superior to dedicated allocation.
