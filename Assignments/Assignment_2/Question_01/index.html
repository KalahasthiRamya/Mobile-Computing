🔍 Critical Inquiry & Conclusion

Key Finding: A wireless link alone merely provides bits over radio waves. When the link breaks (common in mobile environments due to shadowing, tunnels, and cell edges), a purely communication-centric protocol drops packets permanently.
Mobile Computing solves this at the application layer through asynchronous queueing, transactional persistence, conflict resolution, and location awareness. Devices like Case (e) require local SQLite storage and retry workers (WorkManager) rather than synchronous HTTP POST calls.
