⚠️ Stress Test: Can Layer Behavior Nullify Power Savings?

The Conflict Observation:
YES. A power-saving feature at the OS level (such as Doze Mode) can be completely nullified by application behavior.
• When an application holds an unreleased PARTIAL_WAKE_LOCK, the Android PowerManagerService refuses to enter Deep Sleep.
• Even though the screen is off and the user has not touched the device for hours, the CPU stays locked in the C0 power state at 1.8 GHz, draining the battery at 12.5% per hour!
