🔄 Task 1.4: Boundary Test Case Design (1 Mark)

Selected Boundary Case: Screen Configuration Change (Rotation) During Async HTTP Upload:
• Vulnerability: In naive Android code, rotating the screen destroys and recreates the `Activity` (`onDestroy()` → `onCreate()`). If an asynchronous background task retains a reference to the old Activity, it causes a Context Memory Leak, and the callback tries to update destroyed views, crashing the app with an `IllegalStateException`.
• Architectural Fix: Decouple work using Android Architecture Components: perform execution inside an Architecture `ViewModel` with `StateFlow` or defer to `WorkManager`, surviving configuration changes safely.
