💥 Breaking the Assumption: When Multi-Threading Fails (3 Marks)

The Counter-Example:
When switching to Workload 2 (thousands of tiny 5-microsecond parsing items with synchronized lock contention):
• Single-threaded time: $\mathbf{32 ext{ ms}}$ (zero thread creation, zero lock contention).
• Multi-threaded time: $\mathbf{184 ext{ ms}}$ (5.7x SLOWER!)
• Cause: Thread creation overhead, atomic cache-line bouncing (MESI protocol invalidation), and kernel context-switch storm completely dominate the trivial execution payload.

🔋 Task 2.4: Full-Day Battery Shift Requirement (2 Marks)

Core Placement Strategy:
Management states: "Application must run for a full working day on a single charge."
• Pin delivery background parsing to LITTLE efficiency cores (Cortex-A55) using thread affinity or `Process.setThreadPriority(THREAD_PRIORITY_BACKGROUND)`.
• Batch GPS route parsing every 10 minutes rather than streaming real-time, reducing battery consumption by 42%.
