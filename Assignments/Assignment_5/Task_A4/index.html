💬 Critical Inquiry 1: "Runs Slowly on a Phone"

Why "runs slowly" is an inadequate definition:
"Slow" conflates completely different architectural bottlenecks: Is it CPU-bound (complex algorithm), memory-bound (GC thrashing / cache misses), GPU-bound (overdraw), or network-bound (radio RTT and packet drops)? An engineer must specify measured metrics (e.g. 95th-percentile frame time > 16.6ms or radio latency > 250ms) to diagnose the root cause.

💬 Critical Inquiry 2: Local vs Cloud Offloading

Scalability and Security Implications:
• Scalability: On-device processing scales linearly with zero backend server cost ($O(1)$ server compute per user). Cloud offloading creates linear server CAPEX/OPEX.
• Security: On-device processing ensures raw patient bio-data never crosses the network, minimizing GDPR/HIPAA compliance risk.
